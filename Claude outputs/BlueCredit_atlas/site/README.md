# BlueCredit Atlas

Source for https://atlas.bluecredits.org — an interactive U.S. water map by BlueCredit Inc.: water demand by sector (domestic, industrial, agricultural, power plants, data centers), water projects, utilities, drought, streamflow, streamgages, groundwater and watershed features, with downloadable site, basin and utility reports.

Static site (GitHub Pages). See `DEPLOY.md` in the handoff package for setup.
